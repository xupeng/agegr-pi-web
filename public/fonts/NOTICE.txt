Cascadia Code webfont notices
=============================

The four Cascadia Code webfont files in this directory are redistributed
unmodified:

  cascadia-code-latin-400-normal.woff2
  cascadia-code-latin-500-normal.woff2
  cascadia-code-latin-600-normal.woff2
  cascadia-code-latin-700-normal.woff2

They are the "latin" subset, "normal" style, weights 400/500/600/700, as
published in the npm package @fontsource/cascadia-code@5.3.0
(https://www.npmjs.com/package/@fontsource/cascadia-code), which sources them
from the Google Fonts repository
(https://github.com/google/fonts/tree/main/ofl/cascadiacode). The SHA-256 of
each bundled file matches the Fontsource 5.3.0 latin subset byte-for-byte:
