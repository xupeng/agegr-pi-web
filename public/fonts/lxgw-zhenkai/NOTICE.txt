LXGW ZhenKai GB (霞鹜臻楷 GB) webfonts
=====================================

97 `lxgwzhenkaigb-subset-*.woff2` files, each covering one `unicode-range`
slice of the `LXGW ZhenKai GB` family. The slice list is copied from the
`LXGW WenKai Screen` subsets in `public/fonts/lxgw-wenkai-screen/` so a
character that resolves to WenKai at weight 400 resolves to the matching
ZhenKai subset at weight 501-900, and the browser fetches the same ranges.

Source: lxgw/LxgwZhenKai v0.825, asset `LXGWZhenKaiGB-Regular.ttf`
  https://github.com/lxgw/LxgwZhenKai/releases/download/v0.825/LXGWZhenKaiGB-Regular.ttf
  sha256 40876902a7ce25268ab710ad8fe6e2b63bc002aa4b68d22fd45fc1243726ced5
  (17,545,474 bytes)
Upstream project: https://github.com/lxgw/LxgwZhenKai
License: SIL Open Font License 1.1 -- see OFL.txt in this directory. Its
reserved-name grant explicitly allows subsets and WOFF2 conversions made for
web font delivery; these files are only ever served from this app.

How the subsets were built
--------------------------

`scripts/build-content-cjk-fonts.py --subsets` downloads (or takes with
`--ttf`) the pinned release above, checks its size and SHA-256, then runs
fonttools' `pyftsubset` once per slice -- `--unicodes` being that slice's
`unicode-range` from `scripts/lxgw-content-cjk-slices.json`:

  pyftsubset LXGWZhenKaiGB-Regular.ttf --unicodes='U+4e09-4e0b,...' \
    --flavor=woff2 --ignore-missing-unicodes \
    --output-file=lxgwzhenkaigb-subset-<N>.woff2

Rebuilding needs python3 plus fonttools and brotli:

  python3 -m venv .venv && .venv/bin/pip install fonttools brotli
  .venv/bin/python scripts/build-content-cjk-fonts.py --all

The build is deterministic: re-running it against the pinned release
reproduces these bytes and SHA256SUMS.txt exactly.

ZhenKai GB omits some codepoints its WenKai slices cover (emoji, IPA and other
extended Latin, Armenian, Georgian: 980 of 14,492); the browser falls through
to the next family in `--font-content` for those, exactly as it already does
for the WenKai slices, which do not carry every listed codepoint either.

SHA-256
-------

SHA256SUMS.txt in this directory lists the SHA-256 of every subset file. After
changing any font here, regenerate it with the build script:

  python3 scripts/build-content-cjk-fonts.py --subsets

`python3 scripts/build-content-cjk-fonts.py --check` fails when the stylesheet,
the subsets or this manifest drift from `scripts/lxgw-content-cjk-slices.json`
(sorted by filename, which is why the order here is not the slice order).
