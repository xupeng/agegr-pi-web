提交验证结论，不提交原始输出。具体契约见 [质量规范](../frontend/quality-guidelines.md#任务验证产物契约)。

- [ ] 摘要说明命令、环境/依赖树、实测计数、覆盖与未覆盖项、原始证据保留位置。

- [ ] staged 文件和统计中没有原始产物；ignore 是兜底，不允许盲目 `git add -f`。
- [ ] 历史结果仍标为历史结果，不改写成新 SHA 验收。
- [ ] task.json、implement/check.jsonl、Markdown 和产品 fixture 保留；未按全仓扩展名删除。
- [ ] 不把「先提交原始文件，再删除」当成历史清理；历史重写须另有明确授权和独立恢复备份。
