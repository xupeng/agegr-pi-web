# Portable extension prototype design

Extract only schema, validation, formatting and the Pi tool factory into a small local package with SDK 0.85.1 peers and a package-discoverable extension entry. The bridge receives bounded validated questions plus conversation identity and either durably registers an ask or throws; an absent bridge must fail closed. Pi Web continues to inject a host-specific adapter and owns settings, lifecycle, persistence, API/SSE and cards. PA's loader accepts controlled `$PA_HOME/extensions/` entries rather than SDK package discovery, so package installation and host admission must each be tested. First prove the local entry and bridge negotiation under both loader paths; do not bake a speculative ambient global hook into a public API. Retain original validation limits and the existing tool metadata.
