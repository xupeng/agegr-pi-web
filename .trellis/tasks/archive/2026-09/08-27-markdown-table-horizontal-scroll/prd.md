# 改进 Markdown 表格横向滚动

## Goal

避免 Markdown 表格列在窄屏或列数较多时被压缩到难以阅读，改为保留合理的最小列宽，并在表格容器内横向滚动。

## Requirements

- 继续使用现有 Markdown 表格结构和视觉样式，不改变普通 Markdown 内容的布局。
- 表格应至少铺满可用内容宽度；当各列的内容宽度之和超过容器宽度时，表格自身扩宽。
- 溢出仅由 `.markdown-table-wrap` 在水平方向滚动，不撑破消息区域或页面布局。
- 各列应按自身内容宽度自适应，短内容列保持紧凑，不使用统一最小列宽浪费横向空间。
- 长内容列应设置合理的最大宽度并在列内换行，避免单列无限扩张；工具名等中等长度内容不应被挤成逐字/逐词换行。
- 桌面端与手机端都应生效，并保留触摸横向滑动能力。

## Acceptance Criteria

- [x] 多列表格在窄屏下出现容器内横向滚动，页面本身不产生横向溢出。
- [x] 每列按内容宽度自适应，短列保持紧凑，长列达到最大宽度后换行。
- [x] 宽屏下表格仍至少占满消息内容宽度，现有边框、斑马纹和字号不变。
- [x] Markdown 渲染测试覆盖表格滚动容器结构与关键宽度规则。
- [x] 项目完整测试、TypeScript 类型检查以及变更文件的 lint 检查通过。

## Notes

- 现有 `MarkdownBody` 已为表格输出 `.markdown-table-wrap`，本任务主要调整表格的 CSS intrinsic sizing，而不是引入新的渲染依赖。
- `npm run lint` 仍会被仓库已有的 React Compiler memoization 报错阻塞；本次变更文件单独 lint 通过，完整 lint 输出中没有本次功能文件的新问题。
